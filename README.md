## 🌟 Featured Project Spotlight

### 📊 [Web Traffic Analytics & Conversion Funnel Dashboard](https://github.com/mohanasanthibattula-stack/web-traffic-analytics)
> **[🚀 View Live Interactive Dashboard](https://mohanasanthibattula-stack.github.io/web-traffic-analytics/)**

An end-to-end web analytics, conversion funnel diagnostic, and cohort behavioral analysis engine built for multi-channel acquisition tracking.

* **Key Capabilities:**
  * **3-Stage Funnel Diagnostics:** Tracks Top-Funnel drop-off (69.2% leak) and Mid-Funnel form abandonment across landing pages.
  * **Acquisition Attribution:** Analyzes ROI and retention across Google Organic, Instagram (23.66% CR), Email (23.62% CR), Direct, and Referral channels.
  * **Interactive Visualizations:** Dual deliverable featuring a Streamlit web app (`app.py`) and a zero-dependency browser dashboard (`index.html`) using Plotly.js & Tailwind CSS.
  * **Cohort Heatmaps:** PageViews and session duration breakdowns segmented by Device Category and Region.
